Broken URL Checker

Finds only the URLs that are genuinely broken — links that are a single # placeholder, or pages that actually return HTTP 404 or 410. The first run may ask for site access so external URLs can be verified too. SPA hash routes, JS-wired popup & modal triggers, tracking/affiliate URLs, empty or missing hrefs and other HTTP errors (403, 500, 503) are intentionally left out so the list stays clean.

Typography Finder

Live computed fonts and sizes for H1–H6 and paragraphs, plus the most common variants actually used on the page. Each property row is clickable — copy a single value or the whole rule set for a tag.

Media Tracker

Click any icon, image or SVG on the page to track it — only the assets you select appear here, ready for individual download. Inline SVGs are saved as inline-svg-##.svg.

Design Inspector — CSS Copy

Click any element on the page to select it. Its cleaned HTML and scoped CSS are captured instantly and ready to copy — both, or each on its own.

Open the inspector, then hover any element and click it. The floating panel stays compact: one status line plus three actions — Copy HTML, Copy CSS or Copy HTML + CSS. Each copy is a self-contained block: the HTML gets reusable data-wsmcmp markers and the CSS is scoped to the same selector, so paste it anywhere and it works. Press Esc or the “✕” button to exit. Nothing is ever uploaded.

JS Tracker

Live DOM scan of every <script> executing on the page — inline source and external URLs, each script tag’s own ID and classes, plus the parent and containing sections it sits inside. Expand a row to read the raw code, copy it, or hit Locate to flash the exact script tag.

CSS Tools

List every stylesheet on the page, temporarily disable one or all of them to isolate styling problems, and inject a temporary CSS block to preview changes. Everything is non-persistent — a page reload restores the original styles.

Forms Tools

List every form on the page with its fields and validation state. Locate a form, temporarily toggle HTML5 validation (never persistent), or fill fields with visible sample values to test layout — the form is never submitted.

Image Tools

Inspect every <img> on the page: natural vs rendered dimensions, alt text presence, lazy-loading and broken-image flags. Click any row to flash and page-scroll to that image. Hide images to test alternative layouts — reload restores them.

Core Web Vitals

Live values from the page Performance Timeline. LCP, INP and CLS come from real browser entries — if the page did not surface a value, it is shown as "Not available", never estimated.

Debug

Deep programmatic scan of the live page — accessibility gaps, WordPress/Elementor foot-guns, broken media, and responsive overflow. Click a locate button to flash the exact node on the page.

Test on a Device

Pick a device or enter a custom size. You get a live, scale-accurate preview of the page in that device frame plus practical things to check at that width. The page also opens in a privacy-friendly Incognito Chrome tab resized to that viewport, where the responsive check runs against the live page.

Audit File

Generate a complete report of everything this scan found — critical issues, warnings, what is working well, the technology stack and responsive signals. It always works — if no analysis has run yet, the report kicks off a fresh scan of the current page automatically. View it inline, convert it to a Word-compatible Docs file, and download either one.

Site Crawler

Scan the current site's child pages for frontend structure and responsive-layout breakages — layout overflow, viewport problems, icon and CTA issues, design flaws, broken URLs, missing images, and missing structural tags. Pages load one at a time in a silent background tab (a one-time site-access grant is requested, like the Broken Links scanner), then every collected URL is verified and all findings merge into a single site report file.

Version Manager

Every published version of Web Doctor, newest first. The installed release is highlighted, the active one drives which package you restore. Switching saves the chosen version as active and downloads its .zip — to roll back fully, load that folder at chrome://extensions (a running extension cannot replace its own files). The background worker also checks GitHub and raises a browser notification whenever a newer version is published.
